Tentang Saya

Project

MatriksKu

MatriksKu adalah website pembelajaran matematika interaktif yang dirancang untuk

membantu pengguna memahami materi dasar matriks melalui materi singkat dan

latihan soal. Website ini membahas pengertian dan struktur matriks, jenis-jenis

matriks, operasi dasar, transpose, serta determinan dan invers matriks.

Project ini dibuat untuk memenuhi tugas mata kuliah Aljabar linear.

Bahasa: HTML, CSS, dan JavaScript.
